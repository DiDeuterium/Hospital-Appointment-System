# 自我测试说明（数据库 SQL 版）

本文档面向数据库设计课程自测，只使用 SQL 语句验证当前升级版医院预约挂号系统的数据库结构、约束、视图、查询与核心事务逻辑。测试依据为 `sql/schema.sql` 与 `sql/data.sql`，旧版说明保留在 `docs/old/自我测试说明.md`。

## 0. 测试环境与准备

- 数据库：MySQL 8.0+
- 数据库名：`hospital_db`
- 字符集：`utf8mb4`
- 建表脚本：`sql/schema.sql`
- 初始化数据：`sql/data.sql`

```sql
CREATE DATABASE IF NOT EXISTS hospital_db
DEFAULT CHARSET utf8mb4
COLLATE utf8mb4_unicode_ci;

USE hospital_db;
```

初始化时依次执行：

```bash
mysql -u root -p --default-character-set=utf8mb4 hospital_db < sql/schema.sql
mysql -u root -p --default-character-set=utf8mb4 hospital_db < sql/data.sql
```

说明：以下包含 `INSERT`、`UPDATE`、`DELETE` 的测试均建议在事务中执行，并在最后 `ROLLBACK`，避免破坏基线数据。

## 四、核心事务流程测试（TX）

### TX-01 预约挂号事务模拟

```sql
START TRANSACTION;

SELECT rest_quota AS before_rest
FROM schedule
WHERE schedule_id = 16;

INSERT INTO appointment (patient_id, schedule_id, queue_number, status)
SELECT
    1,
    16,
    COALESCE(MAX(queue_number), 0) + 1,
    1
FROM appointment
WHERE schedule_id = 16;

SET @new_appt_id = LAST_INSERT_ID();

UPDATE schedule
SET rest_quota = rest_quota - 1
WHERE schedule_id = 16
  AND rest_quota > 0;

INSERT INTO payment_record (appt_id, amount, pay_status, pay_method)
SELECT @new_appt_id, fee, 0, '模拟支付'
FROM schedule
WHERE schedule_id = 16;

SELECT
    a.appt_id,
    a.patient_id,
    a.schedule_id,
    a.queue_number,
    a.status AS appointment_status,
    p.amount,
    p.pay_status,
    s.rest_quota AS after_rest
FROM appointment a
JOIN payment_record p ON p.appt_id = a.appt_id
JOIN schedule s ON s.schedule_id = a.schedule_id
WHERE a.appt_id = @new_appt_id;

ROLLBACK;
```

**预期结果：** 成功生成新预约；排队号为该排班最大排队号加 1；支付记录为待支付 `pay_status=0`；排班剩余号源减少 1。

### TX-05 管理员审核通过并调整号源模拟

```sql
START TRANSACTION;

INSERT INTO schedule_change_request
    (schedule_id, change_type, target_total_quota, reason, status)
VALUES
    (10, 2, 24, 'SQL自测增加号源', 1);

SET @request_id = LAST_INSERT_ID();

UPDATE schedule_change_request
SET status = 2,
    audit_admin_id = 1,
    audit_time = NOW(),
    audit_remark = '同意调整'
WHERE request_id = @request_id
  AND status = 1;

UPDATE schedule s
JOIN schedule_change_request r ON r.schedule_id = s.schedule_id
SET s.rest_quota = s.rest_quota + (r.target_total_quota - s.total_quota),
    s.total_quota = r.target_total_quota
WHERE r.request_id = @request_id
  AND r.change_type = 2
  AND r.target_total_quota IS NOT NULL;

SELECT
    r.status,
    r.audit_admin_id,
    r.audit_remark,
    s.total_quota,
    s.rest_quota
FROM schedule_change_request r
JOIN schedule s ON s.schedule_id = r.schedule_id
WHERE r.request_id = @request_id;

ROLLBACK;
```

**预期结果：** 申请状态变为 `2` 已通过；排班总号源调整为 24；剩余号源按总号源差值同步调整。
